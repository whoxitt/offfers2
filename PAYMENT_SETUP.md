# Настройка TON-платежей

1. В Railway Variables укажите `TON_WALLET` (кошелёк-получатель, существующий адрес не менять).
2. В TON Console получите API key и добавьте его в `TON_API_KEY`.
3. Установите `PAYMENT_PRICE=5` и `ACCESS_DURATION_HOURS=48`.
4. Добавьте `BOT_TOKEN`, `OWNER_ID`, `DATABASE_URL`.

`TON_API_KEY` — ключ доступа к API, а не адрес кошелька. Пользователь отправляет TON
на `TON_WALLET` с уникальным комментарием, который бот показывает на экране оплаты.
Доступ активируется только после нажатия кнопки проверки и проверки TonAPI.

Проверка не является гарантией теста в основной сети: перед запуском принимайте
реальный тестовый платеж на небольшой сумме в контролируемой среде.
