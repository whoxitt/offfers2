# 💎 Настройка платной версии OfferBot

## 📋 Переменные окружения

Добавь эти переменные в настройки bothost.ru:

### **Обязательные:**
- `PAYMENT_PRICE` - цена доступа в Gram (например: `150`)
- `TON_WALLET` - адрес TON кошелька для приёма платежей

### **Для CryptoBot (опционально):**
- `CRYPTOBOT_TOKEN` - токен от @CryptoBot

---

## 🔧 Как получить токены

### **1. TON Wallet адрес:**
1. Открой Tonkeeper или другой TON кошелёк
2. Скопируй свой адрес (начинается с `UQ...` или `EQ...`)
3. Вставь в `TON_WALLET`

### **2. CryptoBot Token:**
1. Открой [@CryptoBot](https://t.me/CryptoBot)
2. Отправь `/start`
3. Нажми "Create App"
4. Получи API Token
5. Вставь в `CRYPTOBOT_TOKEN`

---

## ✅ Как работает оплата

### **Через CryptoBot:**
1. Пользователь нажимает "Купить доступ"
2. Выбирает "Оплатить через CryptoBot"
3. Оплачивает через @CryptoBot
4. Нажимает "Проверить оплату"
5. Доступ выдаётся автоматически

### **Через Tonkeeper:**
1. Пользователь нажимает "Купить доступ"
2. Выбирает "Оплатить через Tonkeeper"
3. Видит адрес кошелька и **уникальный комментарий (memo)**
4. Переводит Gram с **обязательным** указанием комментария
5. Нажимает "Проверить оплату"
6. Бот проверяет транзакцию через TonAPI
7. Если находит перевод с нужным memo и суммой - выдаёт доступ

---

## ⚠️ Важно

- Для Tonkeeper **обязательно** указывать комментарий (memo)
- Проверка транзакций идёт через публичное API tonapi.io
- CryptoBot работает мгновенно, Tonkeeper может занять 1-2 минуты

---

## 🎯 Тестирование

1. Создай тестового пользователя
2. Попробуй купить доступ
3. Проверь что после оплаты:
   - Статус меняется на "🟢 Активен"
   - Появляется сообщение "Удачного ворка!"
   - Можно отправлять оферы

---

## 📊 Проверка платежей (для админа)

Все платежи хранятся в таблице `payments`:
- `status = 'pending'` - ожидает оплаты
- `status = 'paid'` - оплачено
- `memo` - уникальный комментарий для Tonkeeper
- `provider_invoice_id` - ID счёта в CryptoBot
