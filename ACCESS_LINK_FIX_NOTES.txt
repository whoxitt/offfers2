Исправление ошибки привязки дополнительного аккаунта

Причина по логам:
TelegramBadRequest: chat not found при bot.send_message(owner_uid, ...).
Это не ошибка PostgreSQL. Бот не может написать владельцу основного аккаунта,
пока тот сам не открыл чат с ботом и не нажал Start (/start), либо если он заблокировал бота.

Что изменено:
- TelegramBadRequest/TelegramForbiddenError при отправке запроса теперь обрабатываются отдельно.
- Пользователь получает понятную инструкцию владельцу нажать /start или разблокировать бота.
- В лог записывается ACCESS_LINK_DELIVERY_FAILED, а не ложная ошибка базы данных.
- Привязка по-прежнему не активируется без подтверждения владельца.

Установка на Bothost:
1. Остановить бота.
2. Заменить bot.py из архива.
3. Запустить бота.
4. Попросить основной аккаунт открыть бота и отправить /start.
5. Повторить активацию со второго аккаунта.
Базу данных и ENV менять не нужно.
