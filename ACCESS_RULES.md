ИЗМЕНЕНИЯ ДОСТУПА

1. Пробный доступ отключён: /start больше не выдаёт бесплатные минуты.
2. При подтверждённой оплате доступ активируется атомарно в той же транзакции, что и смена статуса платежа.
3. Добавление твинка инициирует только основной Telegram-аккаунт с активным доступом и хотя бы одной подтверждённой покупкой.
4. Если ранее привязанный твинк сам совершает покупку, его привязка снимается, и он становится самостоятельным основным аккаунтом. Основной аккаунт вводит ID или @username твинка. Твинк получает доступ до той же даты окончания, без отдельного продления.
5. Твинк не может добавить следующий аккаунт. Уже привязанный аккаунт и аккаунт с собственной активной подпиской нельзя привязать повторно.
6. /allow принимает ID или @username и срок: /allow @username 48h, /allow 123456789 7d, /allow @username 30m.
   Число без суффикса считается часами. Максимальный срок — 365 дней.
7. При запуске приложения удаляются оставшиеся записи с source='trial'.

Проверка:
- bot.py и database.py проходят Python compile check.
- Полный сценарий Telegram/TON/PostgreSQL нужно проверить на сервере с реальными credentials и тестовой оплатой.
- Файл .env намеренно не включён в архив, чтобы не распространять секреты. Сохрани свой действующий .env отдельно.

7. Доступ, выданный администратором через админку или /allow (source='admin'), считается полноценным основным доступом для привязки твинков. Сам твинк по-прежнему не может передавать доступ дальше.
