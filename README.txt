# OfferBot

Существующий Telegram Business-бот на aiogram 3 и PostgreSQL. Проект дорабатывается поверх прежней структуры; SQLite не используется.

## Команда офера

Используется только префикс `Оф` (регистр не важен):

`Оф https://t.me/nft/PartySparkler-140864 150 stars`

Язык можно указать в конце команды: `англ/en`, `араб`, `кидай` (китайский). Валюта: `stars`, `gram` или рубли. Получатель для кнопки передачи настраивается командой `/transfer @username`.

Срок нового офера — 23 часа 59 минут. Ожидающие оферы по истечении срока переводятся в `expired`, а не удаляются.

## Стартовое меню и баннер

`/start` показывает фото (если администратор загрузил его через админку) с подписью «Привет, выбери действие» и кнопками «Купить», «Инструкция», «Я чайник». Фото хранится как Telegram `file_id` в существующей таблице PostgreSQL `offer_settings`; после перезапуска оно сохраняется.

Чтобы изменить фото: `/admin` → «Изменить баннер» → отправить фото обычным сообщением. Для отмены отправьте `/cancel`.

## Настройка и запуск

1. Установите Python 3.10+.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте `.env` по образцу `.env.example` либо задайте те же переменные на сервере.
4. Обязательно задайте `BOT_TOKEN`, `OWNER_ID`, `DATABASE_URL` (существующая PostgreSQL) и действующие платёжные переменные, если используется оплата.
5. Запуск: `python bot.py`.

Не добавляйте `.env` в архивы, Git или публичные репозитории.

## Проверки

```bash
python -m py_compile bot.py config.py database.py offer.py payment.py
```

Проверка отправки Business-сообщений, видимости клавиатуры на реальном клиенте, оплаты в TON и сохранности существующей БД требует подключения к реальному Telegram-боту и тестовой/рабочей PostgreSQL. Одного локального `py_compile` для этого недостаточно.
