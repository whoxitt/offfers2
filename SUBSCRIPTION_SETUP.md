# Настройка обязательной подписки на канал

## Как включить/отключить подписку

### Включить подписку (по умолчанию)
```env
REQUIRE_SUBSCRIPTION=true
CHANNEL_ID=@your_channel
CHANNEL_URL=https://t.me/your_channel
```

### Отключить подписку
```env
REQUIRE_SUBSCRIPTION=false
```

## Как работает

**Если включено (`true`):**
- При `/start` пользователь должен сначала подписаться на канал
- После подписки нажать "✅ Подтвердить подписку"
- Только потом получает доступ к меню

**Если выключено (`false`):**
- При `/start` сразу показывается главное меню
- Подписка не требуется

## Получить CHANNEL_ID

1. Добавь бота в канал как администратора
2. Отправь пост в канале
3. Перешли его боту @getmyid_bot
4. Он покажет ID канала (например: `-1001234567890`)
5. Добавь в .env:
```env
CHANNEL_ID=-1001234567890
```

Или используй username канала:
```env
CHANNEL_ID=@channelname
```

## Важно

Секретный код `/code free` работает **без проверки подписки** - для твоих друзей.
