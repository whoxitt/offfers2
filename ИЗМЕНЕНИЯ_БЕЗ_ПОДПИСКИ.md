# Изменения: Полностью убрана подписка на канал

## Проблема
1. Бот требовал подписку на канал для использования
2. Появлялась кнопка "Подтвердить подписку" даже после отключения
3. Ошибка с невалидными URL в кнопках

## Что исправлено

### 1. Полностью убрана логика подписки (файл `bot.py`)

**Удалено/Закомментировано:**

✅ Блок проверки подписки в функции `on_start`:
```python
# УДАЛЕНО:
if cfg.require_subscription and not await is_channel_subscriber(user.id):
    await message.answer(
        "<b>✦ OFFERBOT</b>\n"
        "<blockquote>Оферы на подарки</blockquote>\n\n"
        "Для использования бота подпишись на канал 👇",
        reply_markup=subscription_keyboard()
    )
    return
```

✅ Функция `subscription_keyboard()` - закомментирована  
✅ Функция `is_channel_subscriber()` - закомментирована  
✅ Обработчик `@dp.callback_query(F.data == "check_subscription")` - закомментирован

### 2. Отключено требование подписки (файл `config.py`)

**Было:**
```python

```

**Стало:**


### 3. Исправлены невалидные URL в кнопках (файл `bot.py`)

#### Проблема:
Telegram отклоняет inline-кнопки с невалидными URL (например, `"https://t.me/"` без имени канала).

#### Решение:

**Функция `purchase_success_keyboard()`:**
```python
def purchase_success_keyboard():
    buttons = []
    # Добавляем кнопку чата только если URL валидный
    if cfg.users_chat_url and cfg.users_chat_url not in ("https://t.me/", "https://t.me", ""):
        buttons.append([InlineKeyboardButton(text="💬 Чат покупателей", url=cfg.users_chat_url)])
    buttons.append([InlineKeyboardButton(text="📘 Инструкция", callback_data="show_instruction")])
    return InlineKeyboardMarkup(inline_keyboard=buttons)
```

### 4. Изменены дефолтные значения URL (файл `config.py`)

**Было:**
```python
users_chat_url: str = "https://t.me/"
users_chat_url=os.getenv("USERS_CHAT_URL", "https://t.me/").strip()
```

**Стало:**
```python
users_chat_url: str = ""
users_chat_url=os.getenv("USERS_CHAT_URL", "").strip()
```

## Технические детали

### Закомментированные функции:

Все функции подписки закомментированы, но не удалены - если понадобится восстановить, можно раскомментировать:

- `subscription_keyboard()` - создание клавиатуры с кнопкой подписки
- `is_channel_subscriber()` - проверка подписки пользователя на канал
- `check_subscription_callback()` - обработчик кнопки "Подтвердить подписку"

### Почему возникала ошибка:

Telegram API отклоняет `InlineKeyboardButton` с параметром `url`, если:
- URL пустой
- URL невалидный (например, `https://t.me/` без имени канала)

Ошибка:
```
TelegramBadRequest: Telegram server says - Bad Request: 
can't parse InlineKeyboardButton: Text buttons are not allowed in the inline keyboard
```
